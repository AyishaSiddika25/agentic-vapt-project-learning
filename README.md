# AI-Powered Agentic VAPT Project – Learning Repository

## About

This repository contains my daily learning, research, notes, and implementation progress related to the **AI-Powered Agentic VAPT Project**.

The purpose of this repository is to document my understanding of the project, the technologies involved, the proposed architecture, and the practical implementation work carried out during the development process.

## Project Overview

The project aims to develop an AI-powered VAPT system that can automate and assist security testing activities by combining AI agents with security tools, source-code analysis, DAST, vulnerability validation, risk analysis, CI/CD integration, and reporting.
